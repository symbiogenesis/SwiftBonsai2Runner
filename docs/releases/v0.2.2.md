# Swift Bonsai 2 Runner v0.2.2

Experimental Windows ARM64 release for Snapdragon X and X2 laptops.

## Changes

- Open the portable executable to set up Swift. The app downloads and verifies
  its pinned 6.71 GiB model, adapter and selected runtime automatically. A checkout,
  model lockfile and setup commands are no longer needed for the default model.
- Setup shows its current step and download progress. Pause or close the app to
  stop; partial downloads are retained. **Retry setup** continues in the same
  window while preserving conversations, drafts and response settings.
- Damaged model downloads are repaired only after their replacement passes the
  full length and SHA-256 checks. Runtime repair stages and verifies replacement
  files before publication. Unknown files, unsafe paths and access failures stop
  repair with diagnostics rather than being treated as corrupt downloads.
- Speech setup follows text preparation and has its own retry control. A speech
  setup failure leaves text chat available. Model errors distinguish missing,
  unreadable and mismatched files, with separate guidance for explicit PTQ1.
- Audio-file transcription has labelled controls, elapsed-position progress and
  a bounded, read-only transcript viewer with copy and cancel actions. Reviewing
  a live transcript keeps the completed result in the draft for explicit sending.
- Auto-update can recover damaged staging, treats failed release discovery as an
  error, and binds installation confirmation to the exact verified publication.
  Interrupted confirmation can be retried safely. Unconfirmed process cleanup
  blocks replacement; safely stopped first-run setup can still install an app fix.
- Model-free regression tests cover setup order and pinned identities, interrupted
  and corrupt downloads, transactional repair, option preservation, failure
  boundaries, draft-preserving retry and speech isolation.

## Setup

Download and verify the Windows ARM64 `.exe`, then open it. First launch needs
internet access and free storage for the model, runtime and speech downloads;
repair may need room for both the old file and its verified replacement. The
default data folder is `%LOCALAPPDATA%\SwiftBonsai2`. Existing verified downloads
are reused. No microphone activates during setup.

Use serviced Windows 11 ARM64 and leave **15.5 GiB RAM available** for model startup.
Native speech requires the compatible Microsoft Visual C++ ARM64 runtime. Setup
details provide its download link when speech needs attention. Text chat does not
wait for speech preparation. See [Windows releases](../releases.md).

## Experimental status

Defaults remain Prism **0.1.25**, original Swift PQ2, four CPU row workers, K4/V4
cache with explicit FP16 recovery, and the standard adapter at strength 1.3.
Publisher rollback and PTQ1 remain explicit. PTQ1 requires its reviewed export;
setup never substitutes another model or engine.

The release remains unsigned. Model-free tests do not establish clean-machine
or actual-model acceptance. Hosted release checks, live update/rollback,
full-context quality, sustained performance and isolation retain their gates in
[PLAN.md](../../PLAN.md).
