# Swift Bonsai 2 Runner v0.3.0

Experimental Windows ARM64 release for Snapdragon X and X2 laptops.

## Changes

- The native composer's **Sources** action searches pasted text locally and offers
  exact passages with their original line ranges, source title, author-supplied
  version and complete-source SHA-256. Choose passages, add them to the draft and
  review before ordinary Send. Unselected source text stays outside conversations
  and recovery. This feature does not extend the model's physical context window.
- Audio-file transcription decodes at most one segment ahead while recognition
  remains sequential. A healthy ASR service can stay warm for up to 30 idle seconds
  after complete transcription. Cancellation, failure, conversation changes,
  speech output and shutdown release it. Transcription quality and device speed
  retain their separate acceptance gates.
- Setup presents the current download or local preparation phase in a compact
  native card, with tighter spacing for narrow windows. Application update settings
  and audio transcription controls use the same native presentation conventions.
- Native startup and model failures show compact reports with scrollable details
  and **Copy error** for the complete message. The application and portable launcher
  use the two-leaf icon.
- Broker and speech parsing reject excess array elements and premature multipart
  closing boundaries. Chat validates terminal events before publishing their text.
- Trusted native launch and Retry preserve explicit cache and CPU-placement choices.
  Support depends on the exact reviewed runtime pin; unsupported selections reject
  before inference. A new version alone does not qualify larger context capacity,
  memory reductions or performance.

## Setup

Download and verify `SwiftBonsai2Runner-0.3.0-windows-arm64.exe`, then open it.
Deploy only the executable; the accompanying manifest and checksums verify the
release identity. The native Rust UI, broker, speech companions, maintenance
commands and notices are embedded.

First launch prepares the pinned Swift model, adapter, selected inference runtime
and speech models automatically. Verified downloads are reused. Keep the same
data directory to preserve models, conversations and preferences. No microphone
activates during setup.

Use serviced Windows 11 ARM64 and leave **15.5 GiB RAM available** before model
startup. Native speech requires the compatible Microsoft Visual C++ ARM64 runtime.
Text chat can work before speech preparation finishes. See
[Windows releases](../releases.md).

## Experimental status

Original Swift PQ2, four CPU row workers, the standard adapter at strength 1.3
and explicit FP16 recovery remain available. The release's compiled runtime lock
binds the exact native runtime source, archive and executable identities. Publisher
rollback and the current-weight PTQ1 export remain explicit; setup never silently
substitutes another model or engine.

The release remains unsigned and is prepared for publication as a prerelease.
Hosted packaging checks do not establish clean-machine startup, live update or
rollback, actual-model behavior, full-context quality, sustained performance or
isolation. Those gates remain in [PLAN.md](../../PLAN.md). Historical Prism 0.1.23
timings do not qualify the new runtime dependency selection.
