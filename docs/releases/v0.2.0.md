# Swift Bonsai 2 Runner v0.2.0

Experimental Windows ARM64 release for Snapdragon X and X2 laptops.

The application version and release tag now agree on **0.2.0 / v0.2.0**.
The portable single executable includes the native Rust chat UI, broker, speech
companions, maintenance commands and their license notices. Its Windows GUI
launcher starts without a terminal, and ZIP deflate reduces the embedded payload
while retaining the fixed inventory, expanded-byte bounds and complete hashes.

Release validation can derive the tag from the workspace version. An explicit
mismatch reports the requested and expected identities. Native command failures
retain bounded stdout/stderr diagnostics rather than only the wrapper exit code.

The development runtime remains native Rust Prism **0.1.25**, original Swift PQ2,
four CPU row workers, K4/V4 cache with explicit FP16 recovery, and the standard
adapter at strength 1.3. Publisher rollback is explicit; PTQ1 remains opt-in.
This application version change does not change model or runtime pins or qualify
performance, accelerator use or model quality.

Use serviced Windows 11 ARM64, the compatible Microsoft Visual C++ ARM64 runtime
and at least **15.5 GiB available RAM** before model startup. Model weights,
adapter, inference runtime and speech models remain separate downloads. Preserve
the same user data directory for existing model downloads and conversations.

The release remains unsigned and experimental. Verify downloads against the
published checksums and source identity. Hosted packaging, clean-machine and
installed update behavior, actual-model startup, full-context quality, sustained
performance and isolation acceptance retain their separate pending gates in
[the plan](../../PLAN.md). See [Windows releases](../releases.md) for setup.
