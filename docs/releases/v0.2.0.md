# Swift Bonsai 2 Runner v0.2.0

Experimental Windows ARM64 release for Snapdragon X and X2 laptops.

## Changes

- Application version and release tag agree: **0.2.0 / v0.2.0**.
- One portable executable contains the native Rust chat UI, broker, speech
  companions, maintenance commands and notices. The GUI launcher opens no terminal.
- ZIP deflate reduces the embedded payload while preserving the fixed inventory,
  expanded-byte bounds and complete hashes. No MSI or WiX tool is used.
- Checksums and release metadata accompany the download for verification; only
  the `.exe` needs deployment. Its manifest and notices are embedded.
- Release validation can derive the tag from the workspace version and reports
  requested/expected identities on mismatch. Native command failures retain
  bounded stdout/stderr diagnostics.

## Setup and updates

Use serviced Windows 11 ARM64, the compatible Microsoft Visual C++ ARM64 runtime
and **at least 15.5 GiB available RAM** before model startup. Weights, adapter, inference
runtime and speech models remain separate downloads.

This release has no automatic portable update discovery. Verify the newer
download's published SHA-256, close Swift and replace the executable. Reuse the
same data directory to preserve models and conversations. Automatic download and
confirmed replacement/restart arrive in [v0.2.1](v0.2.1.md); v0.2.0 still requires
manual replacement. See [Windows releases](../releases.md) for setup.

## Experimental status

Defaults remain native Rust Prism **0.1.25**, original Swift PQ2, four CPU row
workers, K4/V4 cache with explicit FP16 recovery, and the standard adapter at
strength 1.3. Publisher rollback is explicit; PTQ1 is opt-in. Model/runtime pins
are unchanged; this version change qualifies no performance, accelerator or quality
claim.

The release is unsigned. Verify published checksums and source identity. Hosted
packaging, clean-machine startup, portable replacement, actual-model startup,
full-context quality, sustained performance and isolation retain their pending
acceptance gates in [PLAN.md](../../PLAN.md).
