# Swift Bonsai 2 Runner v0.1.0

The first experimental prerelease packages the native Rust chat application as
a **Windows ARM64 MSI installer** for Snapdragon X and X2 laptops. Windows is
the only supported application platform.

## Included

- Native Rust desktop chat with conversations, text search, response settings,
  optional encrypted local conversation saving and remembered window placement.
- Rust broker and maintenance tools with locked artifact verification, explicit
  model admission, native Windows process containment and owned shutdown.
- Speech input and output companion executables; compatible ARM64 Microsoft
  Visual C++ runtime and separately provisioned speech models are required.
- Windows Installer registration, Start menu launch, upgrade and uninstall.
- Project and dependency license notices, `SHA256SUMS.txt` and a source-bound
  `release-manifest.json` accompanying the installer.

## Install

Download `SwiftBonsai2Runner-0.1.0-windows-arm64.msi` and check its SHA-256
against the release's `SHA256SUMS.txt`. This first installer is unsigned;
Windows Installer format does not imply Microsoft publisher signing.

Use serviced Windows 11 ARM64 and allow at least **15.5 GiB available RAM**
before model startup. The MSI installs application files without loading a
model. Swift model weights, inference runtime, adapter and optional speech
models are downloaded separately. The model download is approximately 6.71 GiB.
See the repository's
[Windows release guide](https://github.com/symbiogenesis/SwiftBonsai2Runner/blob/main/docs/releases.md)
for setup, prerequisites, data preservation and removal.

## Experimental status

The development default is native Rust Prism **0.1.23**, original Swift PQ2,
four CPU row workers and the standard adapter at strength 1.3. Snapdragon X2
Hexagon acceleration follows the existing runtime policy; this release does
not assert verified NPU use or a performance benefit. Publisher-engine rollback
remains explicit, and lossless PTQ1 remains opt-in. Preparation failures do not
silently change the selected engine or representation.

Full-context and long-conversation acceptance, creative-writing quality,
sustained performance, clean-machine hardware installation, daily-service
recovery and isolation qualification remain pending. Hosted installer checks
verify packaging behavior without loading the model; they do not qualify those
remaining gates. Upgrades and uninstall preserve user model downloads and data.
