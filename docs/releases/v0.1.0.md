# Swift Bonsai 2 Runner v0.1.0

First experimental prerelease for Snapdragon X and X2 laptops: native Rust chat
as a **portable Windows ARM64 executable** or **MSI installer**. Windows is the
only supported application platform.

## Included

- Conversations, text search, response settings, remembered window placement and
  automatic encrypted local saving with a persistent opt-out.
- Rust broker and maintenance tools with locked artifact verification, model
  admission, Windows process containment and owned shutdown.
- Speech input/output companions requiring separately provisioned speech models
  and the compatible ARM64 Microsoft Visual C++ runtime.
- MSI registration, Start menu launch, upgrade, uninstall and background GitHub
  update checks with verified downloads and explicit installation.
- Portable executable containing all five application executables and their
  notices, verified cache extraction and separate owned worker processes.
- Project/dependency notices, `SHA256SUMS.txt` and source-bound
  `release-manifest.json` accompanying the installer.

## Install

Download `SwiftBonsai2Runner-0.1.0-windows-arm64.exe` for portable launch or
`SwiftBonsai2Runner-0.1.0-windows-arm64.msi` for Windows Installer registration.
Verify its SHA-256 against the release's `SHA256SUMS.txt`. Both are unsigned;
MSI format does not imply publisher signing. The portable executable verifies
and extracts its package to the user cache before opening chat.

Use serviced Windows 11 ARM64 with **at least 15.5 GiB available RAM** before model
startup. The MSI installs application files without loading a model. Swift
weights (about **6.71 GiB**), runtime, adapter and optional speech models are
separate downloads. See the
[Windows release guide](https://github.com/symbiogenesis/SwiftBonsai2Runner/blob/main/docs/releases.md)
for setup, prerequisites, data preservation and removal.

MSI-installed chat checks for newer releases, including experimental prereleases.
It downloads and verifies the ARM64 MSI, closes chat normally and hands off to
Windows Installer, which may request administrator approval. No published releases
means no update. Portable bundles require manual verified replacement; source and
preview launches do not update themselves. Upgrades and uninstall preserve model
downloads and user data.

## Experimental status

Defaults: native Rust Prism **0.1.25**, original Swift PQ2, four CPU row workers,
K4/V4 cache with explicit FP16 recovery, and the standard adapter at strength 1.3.
X2 Hexagon acceleration follows runtime policy; NPU use and performance benefit
are unverified. Publisher rollback is explicit; lossless PTQ1 is opt-in.
Preparation failures never silently switch engine or representation.

Full-context/long-conversation behavior, creative quality, sustained performance,
clean-machine installation, daily-service recovery and isolation remain pending.
Hosted installer checks cover packaging without loading the model. End-to-end
application updates still require separate hosted and installed-device acceptance.
