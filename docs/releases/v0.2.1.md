# Swift Bonsai 2 Runner v0.2.1

Experimental Windows ARM64 release for Snapdragon X and X2 laptops.

## Changes

- Portable launches check for newer releases at startup and every six hours,
  including experimental prereleases, and download verified updates. Confirm in
  Settings to close Swift, replace its executable and reopen with the same launch
  options and data directory. Source, manifest and executable are reverified before
  replacement; failed downloads preserve the current app. Manual verified
  replacement remains available.
- Imported audio uses one asynchronous native reader with bounded, backpressured
  segments. Transcription splits near quiet boundaries, carries remaining PCM
  forward and reports progress for memory-admitted recordings. Host-bound ASR
  builds select supported ARM kernels from observed CPU capabilities; device speed
  and transcription quality remain unqualified.
- Context guidance follows broker admission. Native Prism **0.1.25** remains fixed
  at **8,192 tokens**; memory-selected native context requires a separately reviewed
  runtime release. Publisher serving can select context from memory.

## Setup

The portable `.exe` contains the native Rust UI, broker, speech companions,
maintenance commands and notices. Deploy only the executable; use the accompanying
manifest and checksums for verification.

Use serviced Windows 11 ARM64, the compatible Microsoft Visual C++ ARM64 runtime
and **at least 15.5 GiB available RAM** before model startup. Weights, adapter, inference
runtime and speech models remain separate downloads. Reuse the same data directory
to preserve models and conversations. See [Windows releases](../releases.md).

## Experimental status

Defaults remain original Swift PQ2, four CPU row workers, K4/V4 cache with explicit
FP16 recovery, and the standard adapter at strength 1.3. Publisher rollback is
explicit; PTQ1 is opt-in.

The release is unsigned. Verify published checksums and source identity.
Clean-machine launch, live update/rollback, actual-model startup, full-context
quality, sustained performance and isolation retain their acceptance gates in
[PLAN.md](../../PLAN.md).
